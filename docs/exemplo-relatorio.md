# Exemplo de relatório preliminar

Este documento apresenta um exemplo de relatório que o AprovaLex poderá gerar para auxiliar arquitetos, engenheiros e profissionais da construção civil na análise preliminar de aprovação de projetos.

## 1. Identificação da análise

**Tipo de análise:** Aprovação preliminar de projeto arquitetônico  
**Município:** Exemplo  
**Estado:** MG  
**Uso pretendido:** Residencial unifamiliar  
**Responsável pela análise:** Profissional habilitado  
**Status:** Estudo preliminar

## 2. Dados do terreno

| Item | Informação |
|---|---|
| Área do terreno | 360 m² |
| Testada | 12 m |
| Profundidade | 30 m |
| Zoneamento | A verificar |
| Situação do lote | Meio de quadra |
| Uso pretendido | Residencial |
| Número de pavimentos | 2 |
| Área construída prevista | 220 m² |

## 3. Dados urbanísticos analisados

| Critério | Situação | Observação |
|---|---|---|
| Zoneamento | A verificar | Confirmar zona no mapa oficial do município |
| Uso permitido | A verificar | Conferir se o uso residencial é permitido na zona |
| Recuo frontal | A verificar | Consultar exigência mínima na legislação |
| Recuo lateral | A verificar | Verificar regra conforme altura e número de pavimentos |
| Recuo de fundos | A verificar | Confirmar afastamento mínimo obrigatório |
| Taxa de ocupação | A calcular | Comparar área ocupada com limite permitido |
| Coeficiente de aproveitamento | A calcular | Comparar área construída com limite da zona |
| Taxa de permeabilidade | A verificar | Conferir percentual mínimo exigido |
| Altura máxima | A verificar | Confirmar limite para a zona |
| Vagas de garagem | A verificar | Conferir exigência conforme uso e área construída |
| Documentação | A verificar | Confirmar lista oficial da prefeitura |

## 4. Pontos de atenção

- Confirmar a legislação vigente no site oficial da prefeitura.
- Verificar se existem decretos, anexos ou mapas complementares.
- Conferir se o lote possui restrições específicas.
- Validar recuos e índices urbanísticos antes de finalizar o projeto.
- Confirmar a documentação exigida para protocolo.

## 5. Resultado preliminar

A análise ainda não permite afirmar se o projeto está aprovado ou reprovado.

O projeto depende da confirmação das regras oficiais do município e da validação por profissional habilitado.

## 6. Aviso importante

Este relatório é preliminar.

O AprovaLex não substitui análise profissional, responsabilidade técnica, parecer jurídico ou aprovação oficial da prefeitura.
