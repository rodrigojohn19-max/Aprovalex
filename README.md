# AprovaLex

AprovaLex é um projeto open source criado para ajudar arquitetos, engenheiros e projetistas a interpretar leis urbanísticas, códigos de obras e exigências para aprovação de projetos arquitetônicos.

## Problema

A aprovação de projetos arquitetônicos depende da interpretação correta de leis municipais, planos diretores, códigos de obras, leis de uso e ocupação do solo, zoneamento, recuos, taxa de ocupação, coeficiente de aproveitamento, altura máxima, vagas obrigatórias e documentação exigida.

Na prática, essas regras costumam estar espalhadas em documentos longos, escritos em linguagem técnica e jurídica. Isso gera dúvidas, retrabalho, atraso na aprovação, insegurança profissional e prejuízo para clientes e escritórios.

## Objetivo

O objetivo do AprovaLex é criar uma ferramenta aberta para apoiar a leitura, organização e interpretação preliminar de normas urbanísticas.

A ferramenta pretende gerar checklists técnicos e relatórios preliminares para auxiliar profissionais na análise de aprovação de projetos.

## Funcionalidades planejadas

- Cadastro de município.
- Cadastro de tipo de legislação.
- Organização de trechos legais por tema.
- Leitura assistida de leis urbanísticas.
- Checklist de aprovação de projeto.
- Relatório preliminar de conformidade.
- Identificação de recuos, taxa de ocupação, coeficiente de aproveitamento, altura máxima, vagas e exigências documentais.
- Base colaborativa de exemplos por município.

## Público-alvo

- Arquitetos
- Engenheiros
- Estudantes de arquitetura
- Escritórios de projeto
- Consultores de aprovação
- Profissionais de regularização de imóveis

## Status

Projeto em fase inicial de estruturação.

## Aviso importante

O AprovaLex não substitui análise profissional, responsabilidade técnica, parecer jurídico ou aprovação oficial da prefeitura. Ele é uma ferramenta de apoio para organização e conferência preliminar.
