# Roadmap do AprovaLex

## Fase 1 — Estruturação

- Criar documentação inicial do projeto.
- Definir problema principal.
- Definir público-alvo.
- Criar exemplo de checklist.
- Criar exemplo de relatório preliminar.

## Fase 2 — Protótipo

- Criar tela de cadastro do município.
- Criar tela para inserir dados do lote.
- Criar tela para inserir ou colar texto da legislação.
- Criar checklist manual de aprovação.
- Gerar relatório preliminar em texto.

## Fase 3 — Organização das regras

- Separar regras por categorias:
  - zoneamento;
  - recuos;
  - taxa de ocupação;
  - coeficiente de aproveitamento;
  - altura máxima;
  - vagas;
  - documentação.

## Fase 4 — Validação com profissionais

- Testar com arquitetos.
- Coletar feedback.
- Melhorar linguagem.
- Melhorar fluxo de uso.
- Ajustar relatório final.

## Fase 5 — Versão web

- Criar interface web simples.
- Criar banco de dados inicial.
- Permitir exportação do relatório.
- Permitir histórico de análises.
